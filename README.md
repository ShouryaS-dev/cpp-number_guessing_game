# C++ Number Guessing Game

A simple number guessing game I built while learning C++.

## Features

* Random number generation
* Guess range: 1 to 100
* Higher/Lower hints
* Attempt counter
* Input validation for numbers outside the range

## Concepts Used

* Functions
* Loops
* Conditional statements
* Random number generation (`<random>`)
* Nested loops
* Input validation

## Current Limitations

* The program expects numeric input.
* Character input handling will be added in a future update.
